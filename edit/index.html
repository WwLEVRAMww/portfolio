Войдите через Google для доступа к редактору

Настройка редактора

1. Google OAuth

  1. Открой console.cloud.google.com
  2. Создай проект (или используй существующий)
  3. APIs & Services → Credentials → Create Credentials → OAuth client ID
  4. Application type: Web application
  5. Authorized JavaScript origins: https://wwlevramww.github.io
  6. Скопируй Client ID

2. GitHub Token

  1. Открой github.com/settings/tokens
  2. Generate new token (classic)
  3. Scope: repo (только это)
  4. Скопируй токен

3. Вставь ниже

Формат: CLIENT_ID|GITHUB_TOKEN
