## Google Диск
- `SITE.drive = { apiKey, folderId, assetsFolder: "_assets" }`.
- Запросы: Drive API v3 `files.list` с ключом: подпапки корня, затем изображения каждой подпапки (`orderBy=name`, `trashed=false`) с `imageMediaMetadata` (размеры, поворот, EXIF).
- Папки с `_` в начале пропускаются; первое фото `_assets` = фото «Обо мне». Без подпапок все фото корня = одна серия.
- Порядок: `photoOrder` из `packs-config.json`, остальные — по имени; обложка — `coverId`, иначе файл `cover*`, иначе первое фото.
- URL фото: `https://lh3.googleusercontent.com/d/<fileId>=w<ширина>`; ширина подбирается под место (400…2600 px). Отдаёт `Access-Control-Allow-Origin: *`.
- Распределение (`applyDrive`): пул «по кругу» (обложки всех серий, потом вторые кадры, …) → 10 «Избранных», серии = папки, 16 кадров на плёнку (с их пропорциями), 9 для зума (центр — горизонтальный), 14 для следа, по фото на тариф и пункт меню, колесо = 5 плашек из `wheelCards` на позициях 1, 4, 6, 9, 11 + «Это я» + обложки серий.
- Цифры в «Обо мне» считаются сами: число серий, число кадров, `readyDays`.

## Разделы и анимации
Заставка (диафрагма на canvas, счётчик, вспышка) → первый экран (барабан из 4 граней на каждую букву, красный блок со шторками, колесо карточек: автоповорот, скролл, перетаскивание, клик по обложке открывает серию) → ленты → «Обо мне» (подсветка слов, счётчики) → «Избранное» (сетка с параллаксом, видоискатель и EXIF при наведении, фильтр по сериям) → тёмная зона: серии («линза»), плёнка (горизонтальный pin), зум 3×3 → тарифы (липкая стопка) → процесс (DrawSVG) → след из фото → контакты (вариативная толщина букв у курсора, магнитная кнопка, часы МСК) → подвал.
