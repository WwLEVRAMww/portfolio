# Портфолио — Роман Андронов

Сайт: https://wwlevramww.github.io/portfolio/

Одностраничное портфолио с большим количеством анимаций (GSAP + Lenis): заставка-диафрагма, катящееся слово «ПОРТФОЛИО», колесо карточек, курсор-видоискатель, серии «линзой», горизонтальная плёнка, приближение кадра, стопка тарифов, след из фото и т. д.

## Фото — с Google Диска

Сайт сам берёт фото из папки на Google Диске (ID папки и ключ — в `js/content.js`, раздел `drive`):
- каждая подпапка = серия, название папки = название серии;
- папки, начинающиеся с `_`, не показываются; первое фото из `_assets` — фото для «Обо мне» и красного блока на первом экране;
- порядок фото и обложки серий берутся из `packs-config.json`; его меняет редактор `/edit/` (https://wwlevramww.github.io/portfolio/edit/).

Добавил фото в папку на Диске — после обновления страницы оно на сайте. Google отдаёт уменьшенные копии под размер экрана, оригиналы по 20 МБ не грузятся.

Если Диск недоступен, сайт показывает фото из папки `photos/` (`01.jpg` … `24.jpg`, `me.jpg`), а если их нет — заглушки с номерами.

## Тексты и цены

Всё в `js/content.js`: имя, «Обо мне», тарифы, этапы съёмки, контакты. Менять только текст в кавычках.

## Как посмотреть у себя

Двойной клик по `index.html` (для фото с Диска нужен интернет) или `node serve.js` → http://127.0.0.1:8820

## Публикация

GitHub Pages публикует ветку `main`: после `git push` сайт обновляется примерно за минуту.
Старый вариант сайта сохранён в ветке `old-site`.

## Из чего сделано

`index.html` — разметка, `css/style.css` — оформление, `js/` — анимации и данные (`content.js` тексты, `drive.js` фото с Диска, `photos.js` загрузка фото, `hero.js` первый экран, `sections.js` разделы, `lightbox.js` просмотр фото), `edit/` — редактор серий.
Библиотеки в `vendor/`: GSAP 3.15.1 (бесплатная стандартная лицензия GreenSock), Lenis 1.3.27 (MIT). Шрифты в `fonts/`: Unbounded, Onest, JetBrains Mono (SIL OFL).
