# Портфолио Андронов Роман

## Быстрый старт

Откройте `index.html` в браузере.

## Подключение Google Диска

### Шаг 1: Создайте API ключ

1. Откройте https://console.cloud.google.com/apis/credentials
2. Нажмите **"+ Create Credentials"** → **"API key"**
3. Скопируйте ключ

### Шаг 2: Включите Google Drive API

1. Откройте https://console.cloud.google.com/apis/library/drive.googleapis.com
2. Нажмите **"Enable"**

### Шаг 3: Подключите к сайту

Откройте `index.html`, найдите строку:

```javascript
driveApiKey: "",
```

Вставьте ключ:

```javascript
driveApiKey: "ваш_ключ",
```

### Шаг 4: Настройте папку

1. Убедитесь что папка на Диске расшарена публично:
   - ПКМ по папке → **Общий доступ** → **Все, у кого есть ссылка** → **Читатель**
2. ID папки уже указан в коде: `driveFolderId`

## Структура папок

```
📁 Ваша папка (корень)
├── photo1.jpg
├── photo2.jpg
└── ...
```

- Если подпапки есть — каждая = один пакет работ
- Если подпапок нет — все фото = один пакет
- Файл `cover.*` или первое фото = превью
